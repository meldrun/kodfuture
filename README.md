## Краткое описание программы

Консольное приложение для учета личных расходов с возможностью визуализации данных. Программа позволяет добавлять, просматривать, удалять и фильтровать расходы, а также строить графики распределения трат по категориям.

### Ключевые возможности:
- Добавление обычных и крупных расходов (от 10 000 руб.)
- Просмотр всех записей
- Удаление записей по номеру
- Фильтрация по категории расходов
- Фильтрация по временному периоду
- Подсчет суммы расходов за выбранный период
- Визуализация расходов по категориям (столбчатая диаграмма)
- Автоматическое сохранение и загрузка данных в JSON
- Валидация ввода (отрицательные суммы, формат даты)

### Используемые технологии:
- Python 3.7+
- Библиотеки: `datetime`, `json`, `matplotlib`, `abc`
